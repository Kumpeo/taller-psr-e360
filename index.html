Cómo funciona por dentro (todo gratis y abierto)

  • Frontend: un único archivo HTML con JavaScript puro. No usa frameworks, servidores ni cuentas.
  • Audio: Web Audio API del navegador. Usa AnalyserNode con FFT de 8192 puntos y una ventana de 2048 muestras para el pitch.
  • Notas: algoritmo YIN (de Cheveigné y Kawahara, 2002) con interpolación parabólica y un seguidor de notas que reconoce las repeticiones por ataque.
  • Acordes: cromagrama de picos espectrales (60–2100 Hz) que se compara por correlación con plantillas de 10 tipos de acorde. Exige que suenen todas las notas del acorde (la quinta puede omitirse).
  • Ritmo: detector de ataques por salto de energía. El pulso se evalúa por intervalos entre golpes, así la latencia del micrófono no afecta la nota.
  • Timbre: centroide espectral, para comparar el brillo entre voces del teclado.
  • MIDI opcional: Web MIDI API, en Chrome o Edge, si tu teclado o una interfaz USB‑MIDI lo permite.
  • Progreso: se guarda en el almacenamiento local de este navegador y no se envía a ningún lado.

El micrófono y el MIDI requieren abrir la página como archivo propio (por ejemplo, con python -m http.server y entrando a localhost, o en un hosting gratuito con HTTPS). En vistas incrustadas el navegador los bloquea. Ahí puedes subir una grabación hecha con el celular.
